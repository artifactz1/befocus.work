## Phase Goal

**As a** person who works in focus blocks, **I want to** note what got done at each break and see an
honest summary and history of my sessions, **so that** I can see what I actually did and what to
change next time.

<objective>
Pure logic behind the Log page list and the What to improve panel, test first.

Purpose: LOG-04 (browse past sessions grouped by day), LOG-05 (rule-based observations with
evidence and charts).
Seams consumed: `History` from 10-01 (records, logs, notes, links), `buildSummary` / `makeFormat`
from 10-04.
Output: lib/logs/history.ts, lib/logs/insights.ts, two check scripts.

Discretion decisions recorded here (CONTEXT Claude's Discretion: rule set and thresholds):
- Five rules, the UI-SPEC section 6 templates verbatim: Added time, Skipped block, Cut breaks (with
  the Scattered-after-cut sentence when k >= 2, covering CONTEXT's "focus rating after cut
  breaks"), Carried tasks (CONTEXT "tasks left open": a task with fate 'next' in 3 or more session
  notes counts once), Deep time of day (3+ Deep-rated blocks; time = the hour after the 75th
  percentile start, formatted with `makeFormat().clock`).
- Strength = n / m (matching / looked at); ties keep the table order.
- "Finished session" = a session with a note row (10-04 status 'finished'); stopped sessions show
  in history but do not count toward the 3-session gate or the rules.
- Evidence bars use the occurrences the rule looked at, oldest left, last 10 kept, minimum 6 (fewer
  -> pad with 'none' bars on the left).
</objective>

  <name>History grouping and improve rules</name>
  <files>apps/next/src/lib/logs/history.ts, apps/next/src/lib/logs/history.check.ts, apps/next/src/lib/logs/insights.ts, apps/next/src/lib/logs/insights.check.ts</files>
  <behavior>
    - splitSessions(history): one entry per sessionId with its records, logs, links and note
    - sessionDigest(session, tasks, fmt): { sessionId, status, end, focusSeconds, tasksDone, tasksTotal, firstLog (first non-empty log line or null), cells (kind, outcome, seconds for the mini strip) } built from buildSummary
    - groupSessions(digests, now, fmt): [{ label 'Today' | 'Yesterday' | 'Mon 20 Oct', sessions newest first }], days newest first, using local day boundaries of fmt's timeZone
    - improveState(sessions, now): { finished: number, ready: finished >= 3 } counting only finished sessions in the last 14 days
    - observations(sessions, now, fmt): at most 3, each { id, text, bars: { value 0.2..1, status 'happened' | 'not' | 'none' }[] (6-10), label 'n of m sessions had added time' }
    - Added time rule fires at 3 of 5 sessions with added seconds; text names the block with the most added time and suggests a first block of (planned + average added) minutes rounded to 5
    - Rules with 2 occurrences do not fire; zero firing rules -> []
    - A session whose records include the last block (all blocks ended, as at Finish session) but which has no note row stays status 'stopped' in sessionDigest and is not counted by improveState. The 10-11 note write on summary mount is what makes it 'finished'
    - planVsActual(sessions, now, fmt, rows): newest first, { day 'Tue 21', plannedMinutes, focusedMinutes, addedMinutes }, scale = max over rows of max(planned + added, focused)
    - calendar(sessions, now): 35 cells Monday-start ending in the week of now, { date, minutes, level 0-3, today, future }; level 0 = 0, 1 = under 60, 2 = 60-119, 3 = 120+
  </behavior>
  <implementation>
history.ts exports `type HistorySession = { sessionId; records; logs; links; note }`,
`splitSessions(history: History): HistorySession[]`, `type SessionDigest`,
`sessionDigest(session, fmt)`, `groupSessions(digests, now, fmt)`. Tasks are not needed: links carry
text (10-01 `HistoryLink.text`); pass `tasks: []` and `live: false` to buildSummary.
insights.ts exports `type Observation`, `improveState`, `observations`, `planVsActual`, `calendar`.
All take `now` as a parameter; no `Date.now()` inside. Checks build small fixtures with
`makeFormat('en-GB', 'UTC')` and run under `TZ=UTC`.
  </implementation>
</feature>
