## Phase Goal

**As a** person who works in focus blocks, **I want to** note what got done at each break and see an
honest summary and history of my sessions, **so that** I can see what I actually did and what to
change next time.

<objective>
Lay the shared data contract for Phase 10: the zod types for block logs, session notes and the
history payload, the two new tables, the tasks later columns, and migration 0015 written by hand.

Purpose: every later plan (API 10-03, pure logic 10-04 / 10-05, guest storage 10-06, Later 10-07)
builds on these names. LOG-02 (log attached to its block), LOG-06 (same shape in the browser),
LOG-07 (later flag).
Seams consumed (10-CONTEXT "Dependencies and Seams"): Block record, Session id, Plan and links,
Tasks, End of session, Break start, Preferences, Routing. Task 1 re-checks each against the code.
Output: packages/types/logs.ts, tables/logs.ts, tasks later columns, 0015 SQL + snapshot + journal.

Discretion decisions recorded here (CONTEXT "Claude's Discretion"):
- A log is its own table `block_logs` (not columns on `focus_blocks`): records arrive through the
  Phase 8 async queue, a log can be written before its record lands, so `block_id` has no FK.
- The Next time note, free-text done items and the carried tasks with their fate live in one
  small table `session_notes`, one row per (user, session). A note row
  also marks a session as finished in history (10-05).
- No pending carry list: 10-08 / 10-10 plan "Next session" tasks straight into the fresh plan
  that Phase 9 `closePlan` already creates.
</objective>
