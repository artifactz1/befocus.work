## Phase Goal

**As a** person who works in focus blocks, **I want to** note what got done at each break and see an
honest summary and history of my sessions, **so that** I can see what I actually did and what to
change next time.

<objective>
The session seams the break modal and the summary hang on, with no UI.

Purpose: LOG-01 (break prompt moment), LOG-03 (summary from the ended session's own records).
Seams consumed: End of session (`commit` in useTimerStore, the finish step that starts a new session
id with `completed: true`, `resetAll` clearing `completed`), Break start (the run's
`currentBlockId` moving to a break block while `status === 'running'`), Plan and links
(`usePlanSync` onTimer, `closePlan` clearing `links`), `assignTask` in usePlanActions,
`finishedRecords` from 10-04.
Output: edits to useTimerStore.tsx, useToDoStore.tsx, usePlan.ts; lib/logs/break-prompt.ts + check.

Discretion decisions recorded here (CONTEXT: store shape is Claude's discretion):
- `finished: { sessionId: string; records: BlockRecord[] } | null` lives on the timer store and is
  not persisted. The run itself is not persisted either: a reload starts a fresh idle run with
  `completed: false`. So `completed` and `finished` are always set together within one page life,
  and no reload guard is needed. 10-11 makes the ended session count as finished by saving its note
  when the summary mounts.
- `endedLinks: TaskLink[] | null` lives on the tasks store, not persisted, cleared by 10-11 on Start
  new session.
- The break prompt is a pure predicate; the modal (10-09) holds its own open state and the set of
  prompted break ids.
</objective>
