## Phase Goal

**As a** guest using the timer without an account, **I want to** have every block I run kept as a
record in this browser, **so that** my focus history exists before I ever sign up.

<objective>
Sixth slice: guest persistence of block records (CONTEXT: guests keep records in browser storage).
A small storage module merges records by id and caps them; TimerStoreProvider gains a `mode` prop
and routes 08-01's `onRecords` into it for guests. Account mode is wired to a sink in 08-08.

Purpose: BLK-03 (each block becomes a record) and BLK-04 (records carry planned / actual / added
time, start, end and outcome; re-runs update the same record) for guests.
Output: lib/blocks/block-records.ts and its check; provider mode prop; both shells pass the mode.
</objective>
