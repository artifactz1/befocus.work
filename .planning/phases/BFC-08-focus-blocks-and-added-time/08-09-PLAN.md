6. BLK-03 / BLK-04 records: after checks 1-5, `eval` the stored records: one per started block,

   outcome 'reset'. Skip forward from an ended block: its record keeps outcome 'finished'.
7. Console: no errors or hydration warnings on /guest through the run (`console`).
8. BLK-03 / BLK-04 close mid-block: start a block, wait 5 s, reload; the stored records hold that
   block's id with outcome 'reset' and actualSeconds about 5; repeat with the block paused.
