## Phase Goal

**As a** person running focus sessions, **I want to** keep my tasks in a Tasks card that sits in the
same Quiet Deck slot as the record room, **so that** my task list lives next to the timer instead of
in a separate popover.

<objective>
First slice of Phase 9: move the Quiet Deck to one open-card value shared by every deck card (the
record room today, the Tasks card in 09-03), lift the record room's card effects into a shared
hook, and remove the old to-do-list popover and drawer wiring so 09-03 reshapes the tasks store
against a clean type check.

Purpose: TSK-01 (tasks live inside the session surface). The footer Tasks entry returns in 09-03
(wave 2) as TasksButton, which opens the Tasks card built on this deck value.
Seams consumed: none from other phases (Phase 7 record room shell, already shipped). Task 0 checks
the interfaces below against the code before any change.
Output: useDeckStore (with useDeckRootAttrs and useDeckCard), migrated record room consumers, Timer strip rule, footers without
the to-do-list components, to-do-list directory deleted.
</objective>
