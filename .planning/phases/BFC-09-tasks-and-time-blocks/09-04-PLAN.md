## Phase Goal

**As a** person keeping a task list for my focus sessions, **I want to** find my tasks exactly as
I left them after a refresh, as a guest in this browser or signed in on any device, **so that** I
never retype my list.

<objective>
Make the Tasks card's list durable. Guests persist through Phase 3's browser-storage helper with a
validated read; signed-in users get their tasks in the server render through the FND-05 hydration
owner, replacing the client-side PrefetchUserTasks. Harden the task routes at the boundary.

Purpose: TSK-01, ROADMAP SC1.
Seams consumed (09-CONTEXT "Dependencies and Seams"): **Guest storage** (Phase 3 browser-storage
helper and FND-05 hydration owner). Task 1 checks it before any change.
Output: tasks-storage module plus check, guest persistence in the tasks store, getUserTasks server
helper, load-error and guest footnote UI, ownership-scoped task delete and text cap.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser storage -> app | Guest task data is read back from localStorage, which any script or extension on the origin can alter |
| browser -> API | Task bodies and ids from the client |
| Next server -> API | Server render forwards the user's cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05 | Tampering | parseGuestTasks | mitigate | Zod envelope plus per-item safeParse, uuid ids, 1-500 text, item cap 1000; invalid items dropped; check script covers it |
| T-09-06 | Elevation | DELETE /user/tasks/:id | mitigate | Delete where `and(eq(tasks.id), eq(tasks.userId, user.id))` |
| T-09-07 | Denial of service | POST/PUT /user/tasks | mitigate | drizzle-zod refinement `trim().min(1).max(500)` on text at the route boundary |
| T-09-08 | Information disclosure | getUserTasks | mitigate | Forwards only the request's own cookie; logs status only, never task text |
| T-09-09 | Tampering / XSS | rendering restored guest text | mitigate | Text rendered as React text children only (09-03 gate) |
</threat_model>
