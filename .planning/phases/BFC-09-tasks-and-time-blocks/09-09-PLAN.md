## Phase Goal

**As a** person in a focus block, **I want to** pick the task I am working on in one tap and tick
it off **so that** the block's record afterwards shows what I worked on and finished.

<objective>
Ship the now pick (TSK-02): the derived "now" task, the now line under the timer, the "Working on"
popover, "Set now" and the Now tag in the Session card and List, and the done-row task list in the
Session card read from the open plan's links.

Purpose: TSK-02 and ROADMAP SC2 (the writes and the in-session list; the read path that outlives
the plan lands in 09-10).
Seams consumed (09-CONTEXT "Dependencies and Seams"): **Explicit block end and added time** (the
current block and whether it is a running focus block) and the Phase 8 contents of the timer's
`.under` slot, which the now line shares. Task 1 checks them.
Output: now.ts plus check, `useNow` and `setNow` / `markDone` in usePlan.ts, NowLine, BlockTasks,
PlanTab and ListTab now states, Timer.tsx mount.

This plan runs in the same wave as 09-08 and shares no file with it. 09-08 adds the
`.bf-chrome-dim` class, the `--idle-opacity` variable and the `:has([data-now-pick])` idle
exclusion to globals.css; this plan only applies the class name and the variable. The idle opacity
and popover-awake checks run in 09-11, after both plans land.
</objective>
