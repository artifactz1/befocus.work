## Phase Goal

**As a** person in a focus block, **I want to** pick the task I am working on in one tap and tick
it off **so that** the block's record afterwards shows what I worked on and finished.

<objective>
Ship the block record data path for TSK-02: a read of a block's worked and completed tasks that
outlives the plan, for signed-in users (GET /user/task-links?blockId) and guests (the
`befocus.taskLinkHistory` browser key filled when a plan closes).

Purpose: TSK-02 and ROADMAP SC2 (the record lists the tasks after the session closes).
Scope: there is no block-record UI in Phase 9. The Session card's done rows (09-09) read the open
plan's store links only. Phase 10 (LOG-03 / LOG-04) owns the record view and reads this data via
GET /user/task-links?blockId (signed in) or `befocus.taskLinkHistory` (guest). No schema change,
so this plan has no db:push.
Seams consumed (09-CONTEXT "Dependencies and Seams"): **Block record** (records reuse the plan's
block ids, so links by block id are the record's task list) and **Guest storage**. Task 1 checks
them.
Output: block tasks schemas and route, guest link history helpers plus check, the guest close-path
append.
</objective>
