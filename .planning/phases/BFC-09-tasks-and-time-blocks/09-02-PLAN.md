## Phase Goal

**As a** person about to start a focus session, **I want to** see the session laid out as a column
of blocks with real clock times and shape it (add, remove, lengthen) **so that** I know when each
block ends before I begin.

<objective>
The data half of the Plan tab: shared plan types, a pure plan module with its check, a
`task_plans` table, and GET/PUT/DELETE /user/plan on the typed client, pushed to the dev database.
09-05 builds the Plan tab UI, guest storage and seeding on top of it.

Purpose: TSK-03 (plan the blocks of a session; the column is also the live Session card in 09-07).
This plan runs in wave 1 beside 09-01 because it touches no frontend component and no file 09-01
owns.
Seams consumed (09-CONTEXT "Dependencies and Seams"): **Session id** (Phase 8: the timer store
knows the session id before the first block; the plan row stores it). Task 1 checks it.
Output: packages/types/plan.ts, lib/plan/plan.ts plus check, plans table and route trio wired in
app.ts, task_plans in the dev database.
</objective>
