## Phase Goal

**As a** person in the middle of a focus session, **I want to** open the session card and see which
blocks are done, where I am in the current one, what is ahead and how much time I added **so that**
I know how the session is going without doing the maths.

<objective>
Connect the plan to Phase 8's live block list. The plan seeds the timer store before the start and
keeps ahead blocks in sync while live; the Plan tab renders the live state (the Session card) from
one shared session view that 09-08 and 09-09 reuse; the plan closes when the session finishes or
resets.

Purpose: TSK-04 (one view of the running session), TSK-03 (the plan actually drives the session).
Seams consumed (09-CONTEXT "Dependencies and Seams"): **Block list in the store**, **Session id**,
**Explicit block end and added time**, **Block record** (records reuse the plan's ids), all Phase
8. Task 1 maps them and stops on a missing capability.
Output: pure live-view and reconcile functions with checks, usePlanSync and useSessionView, live
PlanTab states and completion writes.
</objective>
