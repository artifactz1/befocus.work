<interfaces>
Timer state shape the rules read (apps/next/src/store/useTimerStore.tsx `TimerState`):
`sessions: number; workDuration: number (seconds); breakDuration: number (seconds); currentSession: number; isWorking: boolean; timeLeft: number (seconds); isRunning: boolean`.
At the natural end of the last round `timeLeft === 0` while `isRunning` stays true (RESEARCH Pitfall 1).

Contract this plan creates (plan 03 and 04 consume it; units are minutes for focus/break and a count for rounds):
- `type LimitKind = 'focus' | 'break' | 'rounds'`
- `LIMITS: Record<LimitKind, { min: number; max: number; step: number }>` = focus {5, 90, 5}, break {5, 30, 5}, rounds {1, 12, 1}
- `type TimerSnapshot = { isRunning; isWorking; currentSession; sessions; timeLeft; workDuration }`
- `isFresh(s)`: `!s.isRunning && s.isWorking && s.currentSession === 1 && s.timeLeft === s.workDuration`
- `isFinished(s)`: `s.currentSession === s.sessions && s.timeLeft === 0` (ignores isRunning)
- `startAction(s: TimerSnapshot & { askBeforeStart: boolean }): 'open' | 'restart' | 'toggle'`
- `clampToLimit(v, kind)`: `Math.round` then clamp into [min, max], no step snapping (used once on open)
- `stepValue(v, kind, dir: 1 | -1, steps = 1)`: snap an off-grid value to the grid in `dir` (counts as one step), apply the remaining steps, clamp
- `rangeText(kind)`: '5-90 min' | '5-30 min' | '1-12 rounds'
- `limitText(kind, v)`: 'Minimum 5 min' | 'Maximum 90 min' | 'Maximum 30 min' | 'Minimum 1 round' | 'Maximum 12 rounds' | null
- `valueText(kind, v)`: '25 minutes' | '1 round' | '6 rounds'
- `unitText(kind, v)`: 'min' | 'round' | 'rounds'
- `totalMinutes(focus, brk, rounds)` = `rounds * focus + (rounds - 1) * brk`
- `formatTotal(min)`: '2h 55m', '2h' when minutes are 0, '45m' when hours are 0
- `endsAt(nowMs, totalMin)` = `nowMs + totalMin * 60000`
- `ASK_KEY = 'befocus.askBeforeStart'`; `readAskBeforeStart(storage?)`, `writeAskBeforeStart(v, storage?)`

Precedents: `apps/next/src/lib/sounds/sounds.check.ts` and `apps/next/src/lib/customize/customize.check.ts`
(`import assert from 'node:assert/strict'`, plain top-level asserts, final `console.log('<name>.check OK')`).
Panel tokens to copy: `apps/next/src/components/customize/customize-panel.module.css` lines 11-27.
`MenuButton` is not used here; Stepper buttons are plain `<button>`s styled by the module.
React is 18.3.1: refs are not props, so the Stepper takes an explicit `spinRef` prop.
