## Phase Goal

**As a** person starting a focus session in BeFocus, **I want to** set focus, break and rounds in one
centered card at the moment I press Play (and turn that prompt off if I always run the same plan),
**so that** every session starts with the plan I meant without hunting through a footer popover.

<objective>
Vertical slice of the start flow: a user on a fresh session presses Play or Space, the centered card
opens with the steppers, alarm, ends-around time and switch, and Start runs the chosen plan.
Persisted for signed-in users and guests. Edit mode from the footer is plan 04.

Purpose: SES-03 (start card), SES-04 (switch end to end), SES-06 (shell, focus, phone gutter,
motion), SES-01 (capsules visible in the card).
Output: store actions, `useSessionCard`, rewired Play/Space/command entry points, `SessionCard.tsx`,
card shell CSS, AlarmPicker restyle, card mounted in both layouts.
</objective>
