## Sampling Rate

- **After every task commit:** Run the quick run command (before `session.check.ts` exists, `bun run check` alone).
- **After every plan wave:** Run the full suite command.
- **Before `/gsd:verify-work`:** Full suite green plus the manual UAT checkpoint below.
- **Max feedback latency:** 120 seconds.
