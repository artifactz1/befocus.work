## Phase Goal

**As a** person starting a focus session in BeFocus, **I want to** set focus, break and rounds in one
centered card at the moment I press Play (and turn that prompt off if I always run the same plan),
**so that** every session starts with the plan I meant without hunting through a footer popover.

<objective>
Vertical slice of the mid-session flow: the user taps the footer Session settings button, edits the
plan in the same card and saves (with a restart confirm when a session is in progress). Then delete
every piece of the old popover/drawer and number inputs, and align the command menu limits.

Purpose: SES-05 (footer edit card, confirm, old UI removed), SES-01/SES-02 (Stepper is the only
duration control and the command menu shares its limits).
Output: edit mode in `SessionCard.tsx`, `SessionSettingsButton.tsx`, footers rewired, six files
deleted, `useParsedCommands.tsx` on `LIMITS`, dead `useUserSettings` removed.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
