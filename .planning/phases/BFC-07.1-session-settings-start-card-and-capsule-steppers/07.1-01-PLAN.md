## Phase Goal

**As a** person starting a focus session in BeFocus, **I want to** set focus, break and rounds in one
centered card at the moment I press Play (and turn that prompt off if I always run the same plan),
**so that** every session starts with the plan I meant without hunting through a footer popover.

(Derived from the ROADMAP Phase 07.1 goal, which is not written as a user story.)

<objective>
Give the session settings row the "Ask before each session" flag end to end on the API side, with a
generated Drizzle migration, bounded drizzle-zod request schemas, safe handlers, and the client save
hook updated for the new field and toast copy. Observable result: a signed-in curl round trip that
reads and writes askBeforeStart.

Purpose: SES-04 persistence. The server-rendered dashboard (`getUserSettings()` ->
`TimerStoreProvider initialSettings`) gets the flag for free once the column exists, so plan 03 can
show or skip the start card with no flash.
Output: schema column + migration 0010, route/handler changes, `useSession.ts` contract, and a curl
transcript in the SUMMARY.
</objective>
