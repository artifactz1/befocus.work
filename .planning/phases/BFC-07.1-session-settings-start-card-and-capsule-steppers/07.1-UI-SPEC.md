# Phase 07.1 - UI Design Contract: Session Settings Start Card and Capsule Steppers

> Sources: 07.1-CONTEXT.md (locked), ROADMAP Phase 07.1 + SES-01..06, Lavish board
> `.lavish/settings/board.html` (picked: stepper **D · Capsules**, placement **P5 · Center card,
> before you start**, proposed limits). Board CSS is translated onto the real panel tokens from
> `customize-panel.module.css`, `records.module.css` and `add-sound.module.css`.

### Capsule stepper (D · Capsules)

One `Stepper` component, three instances (Focus, Break, Rounds). Markup contract:

```
<div class=stepper [data-at-limit] [data-bump]>
  <div class=stepHead>
    <span id={nameId} class=name>Focus</span>
    <span id={hintId} class=range>5-90 min | Minimum 5 min</span>
  </div>
  <div class=pill>
    <button class=btn tabindex=-1 aria-label="Decrease focus" [disabled]><Minus/></button>
    <span class=value role=spinbutton tabindex=0 aria-labelledby={nameId} aria-describedby={hintId}
          aria-valuenow aria-valuemin aria-valuemax aria-valuetext="25 minutes">
      <span class=read><span class=num>25</span><span class=unit>min</span></span>
    </span>
    <button class=btn tabindex=-1 aria-label="Increase focus" [disabled]><Plus/></button>
  </div>
</div>
```

| Element | CSS (translated from board `.D .*`) |
|---------|-----|
| `.stepper + .stepper` | `margin-top: 16px` |
| `.stepHead` | `display: flex; justify-content: space-between; align-items: baseline; gap: 8px; margin-bottom: 8px; font-size: 13px; line-height: 1.4` |
| `.name` | 600, foreground |
| `.range` | 400, `--panel-muted`, `white-space: nowrap`. At limit: text becomes the limit message, colour foreground, preceded by a 6px `--user-accent` dot (`::before`, `margin-right: 8px; vertical-align: 2px`) |
| `.pill` | `display: grid; grid-template-columns: var(--btn) minmax(0, 1fr) var(--btn); align-items: center; height: calc(var(--btn) + 8px); padding: 4px; border-radius: 999px; background: var(--panel-soft); box-shadow: inset 0 0 0 1px var(--panel-hair)` |
| `.btn` | `width/height: var(--btn); border: 0; border-radius: 50%; background: var(--panel-lift); color: hsl(var(--foreground)); touch-action: manipulation; -webkit-tap-highlight-color: transparent; transition: background-color .15s, color .15s, transform .08s, opacity .15s`; icon 14px, stroke 2 |
| `.value` | `display: flex; align-items: center; justify-content: center; height: var(--btn); overflow: hidden; white-space: nowrap; font-variant-numeric: tabular-nums; outline: none` |
| `.read` | `display: inline-flex; align-items: baseline; gap: 4px` |
| `.num` | 18px/600, `line-height: 1` |
| `.unit` | 13px/400, `--panel-muted`. "min" for Focus/Break; "rounds", or "round" when the value is 1 |
| `--btn` | 36px default; 44px under `@media (max-width: 1023.98px), (pointer: coarse)` (pill becomes 52px tall) |

Stepper states:

| State | Visual |
|-------|--------|
| Rest | Button `--panel-lift` bg, foreground icon; pill `--panel-soft` + hairline |
| Hover (only inside `@media (hover: hover)`, so it never sticks on touch) | Button bg `rgb(255 255 255 / 0.14)` |
| Pressed / held | `:active` and `[data-held]` (set for the whole pointer hold): bg `hsl(var(--foreground))`, colour `#101010`, `transform: scale(0.92)` |
| Focus-visible (spinbutton) | `.pill:has(.value:focus-visible) { box-shadow: var(--panel-ring) }` where `--panel-ring: 0 0 0 2px var(--panel-surface), 0 0 0 3.5px hsl(var(--foreground))` (as in `customize-panel.module.css`) |
| Disabled at limit | Matching button gets `disabled`: `opacity: 0.28; cursor: not-allowed`, no hover/press; `[data-at-limit]` on the stepper swaps the range line for the limit message |
| Value change | `.num` rolls: `roll-up` / `roll-down` keyframes, `translateY(45%)` (or `-45%`) + `opacity 0` -> rest, `0.28s cubic-bezier(0.2, 0.7, 0.2, 1)` |
| Key press past a limit | No value change; `[data-bump]` plays `nudge` on `.value` (`translateX(-3px)` / `3px`, `0.18s`, 2 iterations) |

Behaviour: pointerdown steps once, then after 400ms repeats every 120ms; stop on `pointerup`,
`pointercancel`, `pointerleave` (listen on `window` too, since a button that turns `disabled`
mid-hold may not get `pointerup`) and when the limit is hit. Values outside the range on open
(old stored data) clamp into range; an off-step value (e.g. 27) snaps to the next multiple in the
pressed direction (27 + -> 30, 27 - -> 25). **(discretion)**

Limits: Focus 5-90 min step 5, Break 5-30 min step 5, Rounds 1-12 step 1. Durations convert
to/from seconds at the store boundary only.

## Open and close rules (board `.flow`, locked in CONTEXT)

| Rule | Behaviour |
|------|-----------|
| Opens on | Play button or Space when fresh (not running, `isWorking`, `currentSession === 1`, `timeLeft === workDuration`) or finished (`currentSession === sessions`, `timeLeft === 0`), and the switch is on. Both entry points call one shared "request start". |
| Never on | Resume from pause, skip next/previous, R, or when the switch is off (Play starts straight away). |
| Mid-session | Footer Session settings button (desktop `MenuSettings`, phone `MenuSettingsMobile`) opens the card in edit mode at any time. |
| Start | Apply values, reset to fresh round 1, start. Close. |
| Save, session in progress and focus/break/rounds changed | Restart confirm (below). Confirm -> apply, reset to round 1 and start it running **(discretion: "restarts" means it runs, so the next Play does not re-prompt)**. |
| Save, fresh session | Apply, stay fresh and paused, close. No confirm. |
| Save, only the switch changed | Persist the switch, close. No confirm, no reset. **(discretion)** |
| Cancel, X, Esc, backdrop click | Close, discard card changes, timer untouched. |
| One surface | Opening the card first calls Customize `close()` (`useCustomizeActions`, keeps the live look) and `useSoundsStore.getState().setRoomOpen(false)`. While the card is open the modal backdrop blocks the other triggers. |
| Edit mode while running | The timer keeps running behind the card until Save confirms. |

## Keyboard and focus

| Key | Where | Action |
|-----|-------|--------|
| Space | Dashboard (not in a guarded container) or Play button | Request start (opens card on fresh/finished, else toggles as today) |
| Enter | Anywhere in the card except on a `button` or `[role=combobox]` | Submit: Start (start mode) / Save (edit mode). On buttons, Enter activates that button. Start/Save carry `aria-keyshortcuts="Enter"` |
| Esc | Card | Close as Cancel. If the alarm Select or the restart AlertDialog is open, Esc closes only that layer |
| Tab / Shift+Tab | Card | Cycles inside (Radix trap) |
| Arrow Up / Right | Spinbutton | + 1 step |
| Arrow Down / Left | Spinbutton | - 1 step |
| Page Up / Page Down | Spinbutton | +/- 3 steps, clamped |
| Home / End | Spinbutton | Min / max |
| Space, R | Inside the card | Never reach the timer (`useTimerKeyboard` guards `[role='dialog']`; keep the card without a `data-customize-panel` / `data-record-room` exemption) |

Tab order (DOM order): X -> Focus -> Break -> Rounds -> Alarm select -> Preview alarm -> Alarm
volume -> Ask before each session -> Cancel -> Start/Save. The stepper +/- buttons are
`tabindex="-1"` (spinbutton pattern; keys drive the value).

Initial focus via `onOpenAutoFocus` (`preventDefault` then focus): Start button in start mode,
Focus spinbutton in edit mode. On close Radix returns focus to the element focused before open
(Play button or footer button).

Screen reader: `role="dialog"`, `aria-modal="true"`, labelled by the title, described by the sub
line. Each spinbutton is labelled by its name, described by its range/limit line, and speaks
`aria-valuetext`.

## Motion

Ease `cubic-bezier(0.2, 0.7, 0.2, 1)` (house `EASE`).

| Moment | Full motion | `prefers-reduced-motion: reduce` |
|--------|-------------|------|
| Backdrop open / close | `fade` from opacity 0, 0.2s ease / to opacity 0, 0.15s ease-in (`[data-state='closed']`) | `animation: none` |
| Card open | `rise`: from `opacity: 0; scale: 0.98`, 0.22s EASE (as `add-sound .card`) | `animation: none` (instant) |
| Card close | `sink`: to `opacity: 0; scale: 0.98`, 0.15s ease-in | `animation: none` (unmounts at once) |
| Value roll | 0.28s EASE, `translateY(+/-45%)` + fade | `animation: none` |
| Limit nudge | `translateX(+/-3px)`, 0.18s x 2 | `animation: none` |
| Button press | `transform` 0.08s, colours 0.15s | `transition: none` |
| Switch knob | `transform` 0.15s EASE | `transition: none` |

Use `scale` / `translate` properties (not `transform`) on the card so the centring translate and
the animation never fight.

(`useSaveUserSettings`) runs after and only the toasts above report its result. The hook's current

toast; the switch is stored in localStorage (key `befocus.askBeforeStart`, discretion,
try/catch).
