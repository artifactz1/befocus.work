## Phase Goal

**As a** person who sets up BeFocus to look the way I like, **I want** my look to still be there
the next time I open the app, on this device or another one I sign in on, **so that** I never redo
it and never see the default flash before my look appears.

(Derived from the ROADMAP Phase 3 goal.)

Create `tables/themes.ts` (RESEARCH Pattern 1):

```ts
export const themes = pgTable(
  'themes',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    userId: text('user_id').notNull().references(() => user.id, { onDelete: 'cascade' }),
    name: text('name').notNull().default('My look'),
    look: jsonb('look').$type<Look>().notNull(),
    createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).defaultNow().notNull(),
  },
  t => [index('themes_user_id_idx').on(t.userId)],
)
export type Theme = InferSelectModel<typeof themes>
```

`Look` is a type-only import from `'../../../../types/look'`. Add no drizzle-zod schemas here: the
route validates the look with `lookSchema` itself (03-03).
