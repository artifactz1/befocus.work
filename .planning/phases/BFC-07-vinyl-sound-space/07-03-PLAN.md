## Phase Goal

**As a** person focusing with BeFocus, **I want to** keep my timer in view while the record room is open
and set my alarm with my session, **so that** music never hides the clock and the alarm lives with the
session it ends.

<objective>
Make the timer and chrome react to `html[data-room="open"]` (shrink right on desktop, sit above the sheet
on phone, hide counter, hints and idle fade) and move alarm selection into Session settings.

Purpose: VNL-02 (timer shrinks and keeps running, alarm moves to Session settings). Runs parallel with
07-02, which sets the `data-room` attribute; this plan only reacts to it, so it can be tested by setting
the attribute by hand.
Output: CSS rules, a narrowed alarm effect, AlarmPicker.tsx in both Session settings shells.
</objective>
