## Phase Goal

**As a** focused user on the befocus dashboard, **I want to** open a customize panel and change the
background, type, colour, progress style, density and grain while watching the dashboard react
instantly, **so that** I can make the timer screen feel like mine, then keep it with Apply or throw it
away with Cancel.

<objective>
Slice: a user on a phone (or any window under 1024px) taps Customize in the mobile menu, a feathered
bottom sheet rises to 60% of the screen, they switch sections and change the look while the dashboard
above the sheet updates live, then Apply or drag the sheet away to discard.

Purpose: UX-04 (every control usable on mobile) and the mobile half of UX-05/UX-06. The desktop dock
from 02-02 stays as it is; this plan adds the second shell, the breakpoint switch, the mobile trigger
and the mobile chrome fade. The timer rise/scale above the sheet is plan 02-07 (same wave).
Output: useMediaQuery hook, CustomizePanelMobile shell, sheet styles, mobile trigger, DarkModeToggle
removed, mobile chrome fade rule.
</objective>
