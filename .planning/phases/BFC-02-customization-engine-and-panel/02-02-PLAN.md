## Phase Goal

**As a** focused user on the befocus dashboard, **I want to** open a customize panel and change the
background, type, colour, progress style, density and grain while watching the dashboard react
instantly, **so that** I can make the timer screen feel like mine, then keep it with Apply or throw it
away with Cancel.

<objective>
Slice: a user on / or /guest (desktop) clicks the new Customize button, the Feathered dock slides in,
they pick a background swatch or colour and see the dashboard change behind the feather, then Apply
(kept) or Cancel/Esc/close (snaps back). Theme and Background sections are live; the registry, the
shared body and the full controls kit are built so plan 02-05 only adds three section files.

Purpose: first user-visible proof of ENG-02 and ENG-04 on the real dashboard, plus the whole panel
contract (UX-01/02/03/06, CTL-10).
Output: customize/ components, the dock CSS module, the trigger in the desktop menu, the panel mounted
in both dashboard layouts.

The <1024px bottom sheet and the breakpoint switch are owned by plan 02-06; in this plan the dock
renders at every width.
</objective>
