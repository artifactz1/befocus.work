## Phase Goal

**As a** focused user on the befocus dashboard, **I want to** open a customize panel and change the
background, type, colour, progress style, density and grain while watching the dashboard react
instantly, **so that** I can make the timer screen feel like mine, then keep it with Apply or throw it
away with Cancel.

(ROADMAP Phase 2 `**Goal:**` is prose, not user-story format. This story is a faithful restatement of it
and the five success criteria; nothing is added or dropped. Owner can re-run `/gsd mvp-phase 2` to
lock a canonical story.)

<objective>
Slice: the customization engine exists end to end on the real dashboard. A Look is defined once
(Zod, packages/types), a per-request Zustand store holds active / preview / persisted, and a single
provider effect paints the chosen look onto `<html>` as CSS custom properties and data attributes
that the dashboard background already consumes. With the default look nothing changes visually;
every later plan in this phase only has to call `setPreview` / `apply` / `cancel`.

Purpose: ENG-01 and ENG-03 are the substrate every control in this phase writes through. Doing them
first, alone, means waves 2-4 can run in parallel against a fixed contract.
Output: look.ts, catalog.ts, useCustomizeStore.tsx, customize.check.ts, token CSS, fonts, Toaster,
AppBackground on tokens, the ENG-01 wording fix.
</objective>
