## Phase Goal

**As a** focused user on the befocus dashboard, **I want to** open a customize panel and change the
background, type, colour, progress style, density and grain while watching the dashboard react
instantly, **so that** I can make the timer screen feel like mine, then keep it with Apply or throw it
away with Cancel.

<objective>
Slice: the whole customize story, end to end, on the integrated build. It covers every control, every
close path, every viewport, keyboard only, and then the owner's eyes on it.

Purpose: plans 02-02 to 02-07 each verified their own slice while other plans were changing the same
checkout. This plan proves the combined phase against ENG-02, ENG-04, UX-05 and UX-06, fixes what the
integration breaks, and hands the owner a visual review.
Output: fixes (if any) in whichever file the defect lives in, recorded in the SUMMARY, and the owner's
sign-off.
</objective>
