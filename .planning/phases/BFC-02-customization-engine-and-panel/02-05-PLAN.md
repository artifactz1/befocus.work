**As a** focused user on the befocus dashboard, **I want to** open a customize panel and change the
background, type, colour, progress style, density and grain while watching the dashboard react
instantly, **so that** I can make the timer screen feel like mine, then keep it with Apply or throw it
away with Cancel.

<interfaces>
**Store** (02-01, apps/next/src/store/useCustomizeStore.tsx):
- `useCustomizeStore(selector)`, with state `{ active, preview, persisted, panelOpen }`.
- `setPreview(key: LookKey, value)` Zod-validates and ignores invalid values.
- Look fields used here: `font` (font id), `accent` (lowercase 6-digit hex), `contrast` (0.55-1), `progress` ('none'|'ruler'|'ink'|'edge'), `density` ('compact'|'comfortable'|'roomy'), `grain` (0-1).

**Catalog** (02-01, apps/next/src/lib/customize/catalog.ts):
- `FONTS`: a record keyed `inter-tight`, `editorial-serif`, `mono`, `display-sans`, each `{ label, stack }`. `stack` is a CSS font-family string built from next/font variables.
- `ACCENTS`: 12 lowercase hexes.
- `PROGRESS_STYLES`: `{ id, label }[]`, in the order none, ruler, ink, edge.
- `DENSITIES`: `{ id, label }[]`, in the order compact, comfortable, roomy.

**Controls** (02-02, apps/next/src/components/customize/controls.tsx; read the file for exact props):
- `ControlGroup({ label, hint?, children })`
- `SwatchGroup({ name, legend, options: { value, label, color }[], value, onChange, variant?: 'solid' | 'accent' })`
- `ColorField({ id, label, value, onChange })`
- `RangeField({ id, label, min, max, step, value, format, onChange, hint? })`
- `SegmentedControl({ name, legend, options: { value, label }[], value, onChange })`
- `PickCard({ name, value, checked, onChange, label, children })`
- `Hint({ children })`
- Module classes available from customize-panel.module.css: `.picks` (2-column grid) and `.big` (30px/700 sample).

**Registry** (02-02, sections/index.ts):
- `CUSTOMIZE_SECTIONS: { id: 'theme' | 'background' | 'type' | 'color' | 'style'; label; Component }[]`
- It currently holds theme and background.
- `BackgroundSection.tsx` is the pattern to copy for reading preview and calling setPreview.

- Accent hint: "Used for the timer progress and the session grid"

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| native inputs → setPreview | Radio, colour and range values come from the DOM and can be edited in devtools |
| font stack → inline style | The font-card sample sets fontFamily from the catalog |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-18 | Tampering | Type/Color/Style inputs | mitigate | Values reach CSS only through `setPreview`, which safeParses against the Zod Look schema from 02-01 (enum font/progress/density ids, 6-digit hex accent, contrast 0.55-1, grain 0-1); invalid values are dropped, so a devtools-edited radio value cannot inject CSS |
| T-02-19 | Tampering | font-card inline style | mitigate | `fontFamily` comes only from the `FONTS` catalog constant indexed by the entries being mapped, never from user input |
| T-02-20 | Denial of service | contrast slider | mitigate | The schema floor of 0.55 (D-04, UI-SPEC) keeps the dashboard legible at every setting |
</threat_model>
