# Phase 10.1: Focus panel with a Log tab (INSERTED)

Captain feedback after Phase 10: getting around Plan was awkward, a check mark on a planned task
read as "done", and Log should live in the tasks panel instead of its own page.

## Delivered

- The Tasks panel is renamed **Focus** (captain pick on the review board) and has three tabs:
  List, Plan, Log. The standalone Log toolbar button and the `/log` page are gone; `/log` now
  redirects to `/?panel=log` (or `/guest?panel=log`), which opens the panel on the Log tab.
- Desktop: picking Log widens the card to the full width (left to right, 0.45s), then the
  history list fades in, then the picked session 0.15s later. Shrinks back on List or Plan.
  A full screen button (Log tab only) covers the whole window; Esc leaves full screen first,
  a second Esc closes the panel. An empty log keeps the card narrow. Reduced motion: no animation.
- Phone: Log is the third tab in the bottom sheet, list then detail with a back arrow.
- Plan: no check marks for "in this block". Each open block lists "In Block N" (bar plus remove)
  and "Your tasks" with an Add button; tasks in another block show their block (B1) and a
  Move here button. A ‹ Block N › stepper jumps between blocks.

## Verification

- Guest mode in Chrome at 1440 and 390: tabs, widen and fade timings, full screen, Esc order,
  `/log` redirect, Plan add / move / remove, no horizontal overflow, no new console errors.
- `bun run check` clean, `bunx tsc --noEmit` clean.
- Not verified: signed-in mode (no API dev vars in this environment).
